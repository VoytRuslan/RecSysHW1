# Домашнее задание 1: рекомендательные системы

Войт Руслан, 117 группа, кафедра ММП.

Персональные top-10 рекомендации произведений поэзии на Goodreads Book Graph.
Сравниваются ItemKNN, iALS, EASE, FM с метапризнаками и iALS с собственным мягким таргетом.

## Запуск

Python 3.13 или 3.14
Команды выполняются из этой директории:

```
python -m venv .venv
```

Активировать окружение: Windows — `.venv\Scripts\activate`, Linux/macOS — `source .venv/bin/activate`.

```
pip install -r requirements.txt
```

Откройте `experiments.ipynb` в Jupyter или PyCharm и выполните все ячейки.

`experiments.ipynb` содержит выполненные ячейки, графики, формулы и итоговое сравнение.
Проверенный прогон с фиксированными настройками занял около 10 минут без скачивания данных.
При запуске недостающие исходные данные скачиваются автоматически (около 323 МБ), SHA-256 проверяется.
Данные и результаты подготовки лежат в `data/`, эта папка исключена из Git.

В обычном запуске используются сохранённые настройки, модели обучаются заново на train и train+val.
Для повторного подбора можно выполнить `python scripts/tune.py --model "iALS custom"` или включить
`RUN_SEARCH` в ноутбуке. Полный повторный поиск существенно дольше обычного прогона.

Структура: `models/` — пять реализаций; `utils/` — данные, признаки и оценка;
`scripts/` — подготовка данных и повторный подбор; `results/` — настройки и таблицы результатов.

Кастомный сигнал немного выше базового iALS в сохранённом эксперименте.

Решение находится в `hw1/`; репозиторий подготовлен для публикации в ветке `master`.
